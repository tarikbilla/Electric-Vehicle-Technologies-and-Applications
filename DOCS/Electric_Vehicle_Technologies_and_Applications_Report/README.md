# Report source

LaTeX source for the semester project report, *Modelling and Simulation of a
Battery-Electric Vehicle*.

## Build

```bash
make              # compile main.pdf
make clean        # remove build artefacts
```

`make` uses `latexmk` and falls back to `tectonic` if that is not installed.
Either way the bibliography is processed with `biber`, which the `biblatex`
package requires.

If biber reports a control-file version mismatch, the installed `biber` and
`biblatex` versions are incompatible. Install the `biber` release that matches
your `biblatex`; the compatibility matrix is in the biblatex manual.

## Figures

`figures/` holds the plots the report includes. They are produced by the
simulation, not drawn by hand. To regenerate them after changing the model or
the vehicle parameters:

```bash
cd ../..
python scripts/run_all.py     # writes results/figures/
cd DOCS/Electric_Vehicle_Technologies_and_Applications_Report
make figures                  # copies them here
make
```

## Assumption marking

The project brief requires that constants the manufacturer does not publish be
marked in red. The `\asm{}` macro defined in the preamble does that, and every
estimated value in the parameter table and in the prose is wrapped in it.
